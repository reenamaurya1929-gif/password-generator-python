# Password Generator using Python

A simple Python-based password generator that creates strong and random passwords using letters, numbers, and special characters.

## Features

- Generates random passwords
- Uses letters, numbers, and special characters
- Creates strong and customizable passwords
- Simple and easy to use

## Technologies Used

- Python

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python password_generator.py
